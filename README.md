# Project Structure

This project follows a standard web application structure with Python for the backend and HTML/CSS for the frontend.

## Directory Layout

- `project/`: Contains the core application files.
  - `main.py`: The main Python application file (e.g., Flask or Django app).
  - `templates/`: Stores HTML template files.
    - `login.html`: User login page.
    - `dashboard.html`: User dashboard page.
    - `transfer.html`: Money transfer page.
    - `receiver.html`: Page for receiving money/transaction details.
  - `static/`: Contains static assets like CSS, JavaScript, and images.
    - `styles.css`: Main stylesheet for the application.
